# hack and shmup 草案

新しく作るゲーム、ローグライト風シューターの草案です。"hack and shmup" は仮題で、古典的なゲームジャンルの"hack and slash"と"shmups(shoot them up)"の合成。

## inspired by

- Hotline miami : スピード感のある見下ろし型シューター
- Nethack : 古典的ローグライク
- Vampire Survivor, Rev Sweeper : 敵がたくさん

## objective

- 大量の敵を掻き分けてダンジョン風のマップのフロアを限界まで深く潜る

## grand rule

- プレーヤーは攻撃を受けたら（接触・被弾）即死、フロアの初期位置に戻される
    - デスペナルティは特になし、残機もなし
- 下層ほど敵が強くなり、数が増える
    - 敵が強くなって進めなくなったら終わり（システム的な終わりはない）
- フロアには制限時間あり、超過したら即死

### map

- マップはフロア進行時にランダムに自動生成される
- フロアは複数の部屋からなり、部屋は空洞ではなくランダムな障害物がある
    - 突入するまで部屋の中はよく見えない
    - 基本的には部屋に突入すると敵が反応する
        - 敵は部屋から逃げても追ってくる
- 各フロアにはゴールとなる下り階段がある
    - 階段を登って元のフロアに戻ることはできない

## contorol

- Wasd移動とマウスエイミングの見下ろし型シューティングアクション（過去作のrev-sweeper-revolved類似）
- 左クリックでメインウェポン（単発では弱いが射程無限で連射型のマシンガン）
- 右クリックでサブウェポン（射程が狭く連発できないが広範囲、高威力…など特徴的な武器をいくつか）
- ホイールでサブウェポン切り替え

## enemy

- 数をたくさん出し、物量作戦で追い詰めるのがメイン
- 攻撃を受けたら通常の敵はノックバックさせる
    - 多数の敵に追い込まれても、プレーヤーの立ち回り次第で接触や被弾を回避できる余地を残す

### enemy-sample-1

- 一番弱いのでたくさん出す
- 一定のルールで小部屋を徘徊、プレーヤーを発見したら接触しようとゆっくり接近してくる

### enemy-sample-2

- ほどほどに出す
- その場から動かず、プレーヤーを発見したら遠距離から弾を撃ってくる
- 体力は低い

### enemy-sample-3

- ときどき出てくる
- 一定のルールで小部屋を徘徊、プレーヤーを発見したら盾を構えて障害物や壁に突き当たるまで突進
- 盾は正面の攻撃を防ぐ
- 体力はとても低い
